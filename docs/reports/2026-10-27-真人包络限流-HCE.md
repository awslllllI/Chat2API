# 真人包络限流（HCE）实施报告

> 日期：2026-10-27  
> 触发：工具修复实号冒烟导致两枚 DeepSeek 账号禁言约 3 天；峰值 RPM≈13 仍低于旧默认 24，证明「宽松 RPM」挡不住封号。  
> 目标：把真实消耗压进重度真人网页上沿；少封号优先于 Agent 吞吐。

## 1. 做了什么

- 共识 L1/S1 改为 **Human Conversation Envelope** + **sticky 换号**
- 门闸扩展：回合结束间距+抖动、突发桶、小时窗、会话创建节流、换号惩罚
- 调度：取消健康态 round-robin；fill-first + sticky
- DeepSeek 新建 `chat_session` 计入 `sessionCreatesPerHour`
- 旧 DeepSeek `24/1500` 等宽松配置启动时迁移到 HCE 默认
- UI：包络字段与风险提示；冒烟脚本默认拒绝实号

## 5. 使用提示

1. 重启应用以加载 HCE 与迁移。  
2. Agent 工具多轮会变慢或收到 429——预期行为。  
3. 勿把间隔调回秒级「图快」；双号交替打满是高风险指纹。  
4. 实号脚本：`ALLOW_LIVE_UPSTREAM=1 SMOKE_INTERVAL_MS=35000 ...`
