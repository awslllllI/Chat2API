# 2026-10-28 模型元数据与 DSH 对齐

## 问题

DSH 自定义供应商载入模型时需手填：上下文窗口、最大输出 token、输入类型。标准 `/v1/models` 与 Chat2API 原先都不返回这些字段。

## 改动

### Chat2API

- 新增 `src/main/proxy/config/modelMeta.ts`：内置保守能力目录
- `/v1/models`、`/v1/models/:model` 附带扩展字段：`context_length` / `max_output_tokens` / `input_modalities` 等
- **政策**：官方宣称 1M 但网页通道未核实的，统一封顶 **262144**；已核实 ≤256K 的用文档值

### DSH

已安装（`web` + `desktop` profile）：

- `dsh-model-meta-autofill@0.3.0`（models.dev 补缺，不覆盖已有值）
- `dsh-llm-capabilities@0.1.5`（读网关 `/models` 能力字段）

`desktop` 的 `cordis.patch.yml` 已为 chat2api 模型写入保守 `contextWindow` / `maxTokens` / `input`，避免 models.dev 把 DeepSeek 等填成 1M。

## 使用

重启 Chat2API 与 DSH 后生效。可在 DSH 设置页「模型元数据」「Model Capabilities」核对；也可 `GET http://127.0.0.1:8082/v1/models` 查看扩展字段。
