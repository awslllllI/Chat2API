# 供应商文件 / 图片上传打通

日期：2026-10-28（2026-10-29 补全剩余供应商）

## 共享层

- `src/main/proxy/utils/mediaParts.ts`：从 OpenAI `image_url` / `file` / `input_audio` / `video_url` 提取媒体、解析 data URL / HTTP、文本内联 fallback。
- `src/main/proxy/types.ts`：扩展 `ChatMessageContent` 多模态 part 类型。

## 原生上传（与官方网页一致）

| 供应商 | 能力 | 上游路径 |
| --- | --- | --- |
| DeepSeek | 文件/图片 → `ref_file_ids` | `/api/v0/file/upload_file` + `fetch_files`；有文件时 expert→default |
| MiMo | 文件/图片/音视频 → `multiMedias` | `genUploadInfo` → PUT → `resource/parse` |
| Qwen AI | 文件/图片 → `messages[].files` | `getstsToken` → OSS PUT → `files/parse` |
| Qwen 国内 | 文件/图片 → `messages[].files` | chat2 `getstsToken` → OSS PUT → parse |
| GLM | 文件/图片 → refs | `backend-api/assistant/file_upload`（mediaParts） |
| Kimi | 文件/图片 → `message.blocks[].file` | `/apiv2-files/file/upload` + GetFileParseProgress |
| MiniMax | 文件/图片 → `attachments[]` | `/minimax-cloud/api/v1/uploads/prepare` → OSS FormData → `object_key` |
| Perplexity | 文件/图片 → `params.attachments` | `batch_create_upload_urls` → S3 → `s3_object_url` |
| Z.ai | 文件/图片 → `files[]`（PFS） | `/api/v1/storage/pfs/files/upload` → `pfs_file_id`；成功后剥离 OpenAI image_url |

## 策略约定

- **图片禁止 base64 兜底**：原生上传失败时直接报错（`refusing base64 fallback`）。
- **纯文本文件**在上传失败时才允许 `inlineTextFilesAsPrompt`。
- Kimi / DeepSeek / MiniMax / Perplexity / Qwen / Z.ai 均按各自网页协议挂附件，不再把图片塞进 prompt。

## 网页选项对齐（摘要）

| 供应商 | 选项 |
| --- | --- |
| Kimi | `thinking` + `reasoning_effort`（标准/进阶 → MEDIUM/HIGH）+ `speed`（FAST）+ search tools |
| DeepSeek | `modelType` / search / thinking（`providerModelOptions`） |
| Qwen 国内 | `enable_search` / thinking 模型映射；兼容 `web_search` / `reasoning_effort` |
| Z.ai | `features.enable_thinking` / `auto_web_search` / `vlm_tools_enable` |
| Perplexity | `always_search_override` / `mode: research`（高 reasoning）+ 原生 attachments |
| MiniMax | 网页附件 `attachments`；thinking 内容从 `extra_info.thinking_content` 回传 |
