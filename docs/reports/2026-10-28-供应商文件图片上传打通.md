# 供应商文件 / 图片上传打通

日期：2026-10-28

## 共享层

- `src/main/proxy/utils/mediaParts.ts`：从 OpenAI `image_url` / `file` / `input_audio` / `video_url` 提取媒体、解析 data URL / HTTP、文本内联 fallback。
- `src/main/proxy/types.ts`：扩展 `ChatMessageContent` 多模态 part 类型。

## 原生上传

| 供应商 | 能力 | 上游路径 |
| --- | --- | --- |
| DeepSeek | 文件/图片 → `ref_file_ids` | `/api/v0/file/upload_file` + `fetch_files`；有文件时 expert→default |
| MiMo | 文件/图片/音视频 → `multiMedias` | `genUploadInfo` → PUT → `resource/parse` |
| Qwen AI | 文件/图片 → `messages[].files` | `getstsToken` → OSS PUT → `files/parse` |
| GLM | 文件/图片 → refs | `backend-api/assistant/file_upload`（改用 mediaParts 解析） |

## 文本内联 / 透传（暂无稳定网页上传面）

| 供应商 | 策略 |
| --- | --- |
| Kimi | Connect Chat 无公开 pre-sign；文本文件与小图内联进 prompt |
| Qwen 国内 | chat2 文本通道；内联 appendix |
| MiniMax | `attachments: []` 未接；内联进 `text` |
| Perplexity | `attachments: []` 未接；内联进 query |
| Z.ai | 保留 OpenAI `image_url` 给 VLM；文本文件内联；开启 `vlm_tools_enable` |
