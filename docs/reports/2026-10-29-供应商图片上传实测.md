# 供应商图片上传实测

日期：2026-10-29  
测试照片：`%USERPROFILE%\Pictures\iOS\IMG_0048.PNG`（约 73KB）  
方式：本地代理 `http://127.0.0.1:8082` → `/v1/chat/completions` 多模态（含上传解析等待）

## 结果

| 供应商 | 结果 | 说明 |
| --- | --- | --- |
| Kimi | **通过** | 原生 `/apiv2-files` 上传 + 解析等待后提问成功，模型正确描述图片内容（约 5.7s） |
| GLM | 部分 | `file_upload` 返回来源标识成功，但对话侧模型仍称未见图（挂载字段需再对齐网页） |
| MiniMax | 失败 | `uploads/prepare` 持续 `invalid signature`（设备注册签名正常，预签名链路待修） |
| Qwen 国内 | 失败 | `getstsToken` 在 chat2 / chat2-api / chat-side 均 404（上游路径变更） |
| MiMo | 失败 | 账号 401，需重新登录 |

未配置账号未测：DeepSeek、Perplexity、Z.ai。
